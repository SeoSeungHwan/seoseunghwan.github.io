# Housewarming Menu

QR로 접속하는 집들이 메뉴판용 정적 웹페이지입니다.

## 수정할 곳

- 메뉴 항목: `/Users/lifeplanet/Desktop/메뉴판/script.js`
- 문구/제목: `/Users/lifeplanet/Desktop/메뉴판/index.html`
- 색감/디자인: `/Users/lifeplanet/Desktop/메뉴판/styles.css`

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. 저장소 이름은 보통 `username.github.io` 또는 원하는 이름으로 생성하면 됩니다.
2. 이 폴더 파일들을 저장소에 올립니다.
3. GitHub 저장소의 `Settings > Pages`에서 배포 브랜치를 선택합니다.
4. 몇 분 뒤 발급되는 URL을 QR 코드로 만들면 됩니다.

## 추천

- 실제 있는 술/음료만 `script.js`에서 수정
- `무료`, `추천`, `한 잔` 같은 보조 문구를 실제 가격으로 바꿔도 됨
- 배경 이미지가 필요하면 `styles.css`에 추가 가능
